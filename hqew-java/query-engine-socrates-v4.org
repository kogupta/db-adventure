- Confuse logical plan with SQL AST.
- Confuse Iceberg partition spec with execution partitioning.
- Introduce Arrow as magic; learner must first own a minimal vector/batch model.
- Introduce async as syntax; map it to suspended/pollable query work.

HQEW_DIAGNOSTIC_NOTE:
The book is useful for architecture orientation because it spans the whole pipeline.
It is weak as the sole build-from-first-principles text for a DataFusion-bound learner because many "columnar" operations devolve to boxed row-at-a-time getValue loops; physical properties, memory accounting, async streams/cancellation/backpressure, and production optimizer mechanics are shallow or absent.
Tutor may assign selected sections AFTER learner builds analogous component; never make HQEW chapter order the curriculum.

* 12_TUTOR_HANDOFF_PROTOCOL
:PROPERTIES:
:ID: TUTOR_HANDOFF
:END:

When a new tutor model, new conversation, or resumed session takes over:
1. read BOOT order.
2. do not recap the whole curriculum.
3. treat logged evidence as prior evidence, not guaranteed retained knowledge.
4. ask one retrieval question selected from CURRENT_TASK prerequisites.
5. do not alter prior learner state without new evidence.
6. continue CURRENT_TASK unless retrieval exposes a prerequisite gap.

Tutor identity, model family, effort setting, and tutor efficiency are irrelevant to learner state.
The only tracked state is learning progress, evidence, misconceptions, decisions, and session history.
