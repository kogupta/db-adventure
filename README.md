# db-adventure

A personal learning monorepo for database systems and query engines.

## Projects

- [`intro.db`](intro.db/): exercises and notes based on *Database Design and Implementation*.
- [`parquet-parser`](parquet-parser/): a basic Parquet reader in Rust.
- [`hqew-java`](hqew-java/): the Java 25 learning port of *How Query Engines Work*.

The Kotlin source project for the query-engine book remains outside this monorepo as the reference implementation. The book PDF is intentionally not committed; the local reference file is `~/Desktop/db/database-design-and-implementation.pdf`.
